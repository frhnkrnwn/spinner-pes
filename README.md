# Konami Cup Draw 2026

Interactive 3-player / 9-team balanced draw for PES 2017 Summer Patch 2026.

## GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait for the Pages URL.

No build step or server is required.
